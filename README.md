# 면접 자리 배치

면접 날 학생 명단·자리·진행 상태를 여러 사람이 실시간으로 같이 보는 웹 페이지입니다.

- **가입 없음**: 처음 들어온 사람은 이름(정자)만 적고 권한을 요청합니다.
- **소유자 승인**: 소유자가 「🔑 권한 관리」에서 **관리자**(수정 가능) 또는 **보기**(보기만)로 승인합니다.
- **접속 중 표시**: 지금 페이지를 열어 둔 사람과 직책이 위쪽에 보입니다.
- **자리 없이 완료**: 이미 끝난 학생은 「학생 명단」에서 `완료`를 눌러 바로 처리합니다(`완료 취소` 가능).

화면은 GitHub Pages, 데이터는 Firebase(Firestore)에 저장됩니다. 학생 명단은 이 저장소에 들어 있지 않고 Firebase에만 저장됩니다.

## 처음 한 번 설치 (명령 한 줄)

Windows: 폴더에서 `setup.bat` 을 두 번 누르거나, 이 폴더에서 터미널을 열고

```
node setup.mjs
```

스크립트가 Firebase 프로젝트·익명 로그인·Firestore·보안 규칙·GitHub 저장소·GitHub Pages를 모두 만들고,
마지막에 소유자 링크를 열어 줍니다. 중간에 Google 로그인과 GitHub 로그인 창만 눌러 주면 됩니다.
멈추면 다시 실행하세요. 끝난 단계는 건너뜁니다.

필요한 프로그램(없으면 스크립트가 설치 명령을 알려 줍니다): Node.js, Git, GitHub CLI(gh)

### 소유자
설치 직후 열리는 `주소/#owner` 페이지에서 이름을 적은 브라우저 **한 곳**이 소유자가 됩니다.
다른 기기에서도 소유자로 쓰려면 그 기기에서 이름을 적어 요청한 뒤, 「🔑 권한 관리」에서 **소유자**로 승인하세요.

### 명단 넣기
소유자로 들어가 **더보기 → 엑셀 명단 불러오기** (열 이름: 구분/그룹, 시간, 번호, 이름, 학교, 전화, 비고)

## 같이 쓰는 사람에게 보낼 링크
`https://<주소>/` 만 보내면 됩니다. 받은 사람이 이름을 적고 요청하면 「🔑 권한 관리」에 빨간 숫자가 뜨고, 거기서 직책을 골라 승인합니다.
직책 변경·권한 회수도 같은 화면에서 하며, 바뀌면 그 사람 화면이 바로 새로 고쳐집니다.

## 알아 둘 점
- 권한은 **브라우저마다** 기억됩니다. 다른 기기·시크릿 창·브라우저 데이터 삭제 후에는 다시 요청해야 합니다.
- 면접이 끝나면 Firestore에서 `roster`, `seats`, `log`, `requests`, `members`, `presence` 컬렉션을 지워 학생 정보를 정리하세요.
